TOGBankClassic - Guild Bank Management for Classic Era & TBC

Are you tired of logging into multiple bank alts to find items? Does your guild rely on character banks instead of the guild vault? TOGBankClassic is the solution!

TOGBankClassic is a powerful, feature-rich addon that transforms how your guild manages inventory across multiple bank characters. View, search, and request items from all your guild bank alts without ever logging out—all in one convenient interface.

Core Features

Unified Inventory Management

  • One-Click Access: View the complete inventory of all guild bank characters in a single window
  • No Alt-Hopping: Never log out to check what's in stock—see everything at a glance
  • Real-Time Updates: Inventory automatically syncs across all guild members using the addon
  • Mail Integration: Track items in transit—see what's in the mailbox as part of total inventory
  • Item Tooltip: Hover any item anywhere in-game to see which bankers have it and their exact stock levels—no addon window needed

Powerful Search System

  • Guild-Wide Search: Search across all bank characters simultaneously—find any item instantly
  • Live Filtering: Results update as you type, showing exact quantities and locations
  • Sort Dropdowns: Visual dropdown menus with 6-7 sort modes (A-Z, By Type, By Rarity, By Level, By Bank, By Quantity, By Slot) and reverse order toggle
  • Banker Labels: See which banker character has each item in search results
  • Click to Request: Click any search result to open a request dialog with smart quantity suggestions
  • Availability Info: See max requestable amounts based on officer-configured limits

Smart Request System

  • In-Game Requests: Guild members request items directly through the addon—no whispers needed
  • Request Tracking: View all pending, fulfilled, and completed orders in the Requests window
  • Timeline Tooltips: Hover any request's date to see when it was submitted, filled, or cancelled (with reason)
  • Cancel Reasons: Bankers select a reason before cancelling; reason is stored and shown to the requester
  • Requests Archive: Requests older than a configurable threshold automatically move to an Archive tab, keeping the main view focused
  • Stale Request Management: orders left unfilled past your chosen age close automatically, and officers can clear them in one go with the "Cancel Stale" button
  • Priority System: Mark requests as Rush, High, Normal, or Low priority for better organization
  • Officer Controls: Officers can configure guild-wide request percentage limits (1-100% of inventory)

Automated Order Fulfillment

  • One-Click Fulfill: Bankers click "Fulfill" button—addon automatically attaches items to mail
  • Smart Stack Splitting: Automatically splits oversized stacks with confirmation dialogs
    • Example: Request for 2 Felcloth from a 5-stack? Addon prompts to split precisely 2 items
    • Complex requests (e.g., 175 Runecloth from mixed stacks) handled automatically
  • Optimal Stack Selection: Intelligent bin-packing algorithm selects best stack combinations
  • Visual Indicators: Button icons change to show split needed vs. ready to mail

Blazing-Fast Synchronization

  • Only what changed gets sent. After the first sync, the addon shares just the differences rather than whole inventories — a fraction of the traffic of a full re-send.
  • No single bottleneck. Data comes from whichever guild member has the freshest copy, not from one designated player who has to be online.
  • Log in and catch up. Anything you missed while offline arrives shortly after you log in, without you asking.
  • Built to stay quiet. Traffic is queued and paced so a busy guild chat doesn't get flooded and messages don't arrive garbled.
  • Nothing to configure. All of this runs on its own; there are no sync settings to tune.

Advanced Features

For Guild Members

  • Minimap Button: Quick access to inventory—toggle visibility in options
  • Bag Highlighting: items needed for open orders are marked in your bags — works with the default bags, Bagnon, ElvUI and Baganator
  • Request History: View your past requests with fulfillment status
  • Fair Distribution: Officer-configured limits ensure equitable access to guild resources
  • Window Persistence: All window sizes and positions save automatically across reloads
  • Visual Consistency: Thin 8px scrollbars and unified borders across all windows
  • Mute Warnings: Checkbox to hide low-priority warnings for cleaner chat

For Bank Alts

  • Automatic Detection: Add "gbank" to Public Note or Officer Note—addon handles the rest
  • Auto-Scan: Configure to scan bank/bags/mail automatically when opened
  • Mail Fulfillment: Receive requests, click Fulfill, send mail—streamlined 3-step process
  • Donation Tracking: Optional feature to accept and track donations from guild members

For Officers

  • Request Limits: Set max request percentage (e.g., 50% = members can request up to half of available stock)
  • Protects Unique Items: Always allows requesting at least 1 if available (gear, BoE epics, etc.)
  • Syncs Guild-Wide: your settings reach everyone online straight away, and anyone who was offline picks them up when they next log in — you only set them once
  • Auto-Cancel Threshold: choose how many days an unfilled order stays open before it is closed as stale
  • Custom Cancel Reasons: write your own reasons for cancelling an order, and choose which ones members and bankers each see
  • Help Notes: add a note of your own to each window's help tooltip, so guild-specific rules are visible where people need them

If Something Goes Wrong

  • Built-in logging. Turn it on with /togbank debug, send it to its own chat tab with /togbank debugtab, and grab a copy for a bug report with /togbank debuglog. Off by default, so it costs you nothing when you're not using it.
  • Update notifications. You're told when a newer version is out, so you're not silently running an old one while your guild has moved on.
  • Diagnostics on request. If a problem needs digging into, there are extra tools behind /togbank dev that support can walk you through on Discord.

How It Works

Setup (One-Time)

  1. Bank Characters: Add "gbank" to character's Public Note or Officer Note
  2. Enable Reporting: In AddOns settings, enable "Report bank contents" and "Scan bank on open"
  3. Scan Inventory: Open your bank and then close it — the scan runs on close, then shares with your guild
  4. Done! Inventory is now visible to all guild members using TOGBankClassic

Daily Usage

For Guild Members:

  1. Open TOGBankClassic (minimap button, or type /togbank)
  2. Click "Search" → type item name (e.g., "Felcloth")
  3. Click result → dialog shows available quantity
  4. Enter amount → click "Send Request"
  5. Wait for mail notification—it's that easy!

For Bank Alts:

  1. Open TOGBankClassic → click "Requests"
  2. See all pending requests with quantities
  3. Click "Fulfill" on any request
  4. Addon attaches items (auto-splits if needed)
  5. Type recipient name → send mail → done!

Slash Commands

Everyday Commands

  • /togbank — open or close the main inventory window
  • /togbank help — list every available command
  • /togbank roster — show the bank characters the addon knows about
  • /togbank sync — manually pull the latest data from your guild
  • /togbank share — push your own inventory and requests to the guild
  • /togbank version — show which version you are running
  • /togbank wipeframes — put all windows back to their default positions and sizes

/bank and /gbank can be enabled as shortcuts in the options, if nothing else has claimed them.

Resetting Data

  • /togbank wipe — clear this guild's stored data (it re-syncs from your guild afterwards)
  • /togbank wipeall — clear everything and start fresh

Troubleshooting

  • /togbank debug — turn debug messages on or off
  • /togbank debugtab — send debug messages to their own chat tab instead of cluttering yours
  • /togbank debuglog — print a recent slice of the log to paste into a bug report

There are further diagnostic commands behind /togbank dev, intended for development and support. /togbank dev help lists them; you should not need them in normal play.

Key Settings

Dependencies & Compatibility

Required

All of these install automatically through the CurseForge app — you do not need to fetch them yourself.

  • Ace3 — core framework
  • VersionCheck-1.0 — tells you when a new version is out
  • LibGuildRoster — guild roster and online/offline tracking
  • AceCommQueue — keeps addon traffic orderly so nothing arrives garbled

Optional — bag addons

The "Highlight needed items" option works with the default Blizzard bags and with the bag addons below. The look differs depending on which one you use — that is a limit of what each addon lets others change, not a bug:

  • Bagnon — dims the items you don't need. Limited to the first 20 distinct items.
  • ElvUI — dims the items you don't need, in both the bag and bank windows, using ElvUI's own shading.
  • Baganator — puts a gold marker on the items you do need. Nothing is dimmed, because corner markers are the only thing Baganator lets other addons add.

Compatibility

  • World of Warcraft Classic Era (Interface 11509)
  • World of Warcraft The Burning Crusade (Interface 20506)
  • Works alongside other guild management addons
  • Other bag addons are not interfered with, but item highlighting only supports the four listed above — everything else in the addon works normally regardless of which bag addon you run

Works With the Rest of the TOG Addons

TOG Profession Master

If your guild also runs TOG Profession Master, the two talk to each other automatically — there is nothing to set up on this side beyond having TOGBankClassic loaded.

  • Crafters can see guild bank stock without leaving the profession window. A [Bank] button appears next to any reagent your bankers actually hold — in the recipe breakdown, the cooldown panel, shopping lists and the Reagent Tracker. If nothing is in stock, no button.
  • They can request reagents from there too. Click [Bank], pick which banker to ask, choose a quantity, and the order arrives in TOGBankClassic like any other request — including your officer-configured limits.
  • No duplicate bookkeeping. TOG Profession Master reads the same stock figures this addon already keeps, so there is only ever one set of numbers to trust.

TOG Tools — planned

Not available yet. A bank log is planned, which will surface this addon's guild bank activity inside TOG Tools alongside the rest of its at-a-glance guild information. Listed here so you know it is coming, not as something you can use today — there is no date on it, and nothing in this addon depends on it.

Shared Foundations

The TOG addons are built on a common set of libraries rather than each reinventing the same plumbing:

  • DeltaSync — the guild-sync engine that keeps data current across members
  • LibGuildRoster — guild roster and online/offline tracking
  • AceCommQueue — keeps addon traffic orderly so nothing arrives garbled
  • ItemDB — an offline item database, so item names and details work without waiting on the game to load them
  • VersionCheck — tells you when a newer version is out

In practice that means a fix to the shared sync layer benefits every TOG addon at once, and running several of them costs less than the sum of their parts. Each is published separately and installs automatically through the CurseForge app.

Recent Updates

v1.4.0 (in development) - Guild Roster Overhaul

Not released yet. Listed so you can see what is coming.

New

  • You can now set how see-through each window is. A new Appearance tab in the options has a slider for every window — Inventory, Search, Requests, Donations and the Mail viewer — so you can make the ones you leave open fade into the background and keep the rest solid. Only the window frame fades: item icons, stack counts and text stay perfectly readable at any setting, and a window you drag transparent still moves and closes normally. Changes take effect straight away on a window that is already open, and there is a "Reset All Windows to Solid" button if you overdo it. Note that 100% is now properly solid — the window art was always slightly see-through before and could not be made fully opaque; if you liked that lighter look, nudge the slider down a little. Thanks to Vishiswaz for the request.

Changed

  • Removed: the old way of sharing bank contents is gone entirely, and with it the bug that kept corrupting item data. To save bandwidth, the addon used to strip the item links out of an update and let the receiving player rebuild them — guessing, item by item, whether the person on the other end would be able to. That guess is about somebody else's game client, and when it was wrong the item came back wrong. Bank contents now travel as plain numbers and the item is rebuilt from a shipped item database, so there is no link to strip and nothing to guess. Everyone in your guild needs this version. Until a bank character updates, players on the new version will not see their contents, and vice versa — it sorts itself out as people update, and nothing is lost in the meantime. If someone in your guild is still on an older version, you will now be told so plainly rather than simply seeing nothing from them.
  • Two addons are now installed alongside this one: LibGuildRoster and AceCommQueue. Guild-roster handling and message queueing moved into shared libraries used across the TOG addons, so a fix in either benefits all of them at once. AceCommQueue was previously bundled inside TOGBankClassic and had fallen behind its own newer releases; as a separate addon it stays current. Both install automatically through the CurseForge app — you do not need to fetch either yourself.
  • The setup steps told you to open your bank, when what actually starts a scan is closing it. Your bank contents are read when you shut the bank window, not when you open it — and opening your bags on their own has never started a scan. The instructions in several places said otherwise, so anyone following them exactly could sit with the bank open wondering why nothing had been shared. The wording is corrected everywhere, and the in-game message you get when there is nothing to compare now tells you to open and close the bank.

Fixed

  • Updating the addon no longer cuts you off from guildmates who have not updated yet. We corrected how the addon fingerprints a bank character's contents, so that swapping one random-suffix item for another is actually noticed. That fingerprint is compared between players, so changing it would have meant an updated client and an out-of-date one could never agree again — each convinced the other was stale, re-syncing endlessly, and the whole guild would have had to update together on the same day. The addon now carries both the old and the new fingerprint and uses whichever the two of you share.
  • A completed update could be reported as a failure fifteen seconds later. When bank contents arrived successfully, the addon stored them and stopped — without ever marking the transfer as finished. The countdown that watches for a stalled transfer kept running, and when it ran out it declared the transfer dead and moved on to somebody else, even though it had worked perfectly. It also meant each completed transfer used up one of the addon's limited transfer slots permanently, so syncing got slower the longer you played.
  • An update could be given up on while it was actually working. When everyone holding a bank character's contents was busy, the addon waited and planned to try again. If somebody freed up in the meantime it went ahead with them — but the old plan to try again was still running, and when it came around it declared the whole thing a failure, even though the update in progress was fine. This also meant the same request could be sent twice. Superseded attempts are now dropped properly, while a genuine retry still happens as before.
  • An update for a bank character could be cancelled part-way through by an earlier attempt for the same character. When the addon asked for a bank character's contents and then asked again a few seconds later — which happens on its own when you open your bank, or when it catches up after you log in — the first attempt was still counting down in the background. When it ran out of time it cancelled whatever was happening at that moment, which by then was the second attempt, and reported it as having timed out. The result was an update that stopped for no visible reason and had to be retried. Only one countdown is now kept per character.
  • "Highlight needed items" did nothing at all if you opened your bags in the wrong order. The addon worked out which bag window to dim by counting, which only matched reality when you opened your backpack first and then each bag in order. Open a bag on its own, or open them out of order, and it was looking at the wrong window entirely — so the tick box turned on and absolutely nothing happened, with no error to explain it. Worse, with two bags open the wrong way round it could dim slots in one bag using the size of another. It now asks the game which window is showing which bag, the same way the game itself does, so the order you open things in no longer matters. This also fixes bank bags dimming the slot at the opposite end of the bag from the one actually holding the item.
  • Items sitting in a bank character's mailbox could go missing for everyone else. If the game could not give the addon a full item link for a mail attachment — which happens routinely — that item was quietly thrown away by everyone who received the update, and rescanning never fixed it because the same thing happened every time. Those items now arrive. This is a second, separate cause of "the banker's mail is missing" from the one fixed earlier in this version; that one was about recording mail, this one was about sending it.
  • A bank character's own tooltip could show a smaller count than everybody else saw. Hovering the same item on the bank character and on a normal character gave two different numbers — for example 68 against 71 — and the bank character was always the one that was short. The cause was mail. Your bank vault can only be read while you are standing at a banker, so to avoid wiping a stored vault the addon skipped saving anything at all when you were away from one — which also threw away the mail and bag counts it had just read. Since you almost never open your mailbox standing at a banker, mail could never make it in. The vault and your bags and mail are now stored separately, so being away from a banker simply leaves the vault untouched instead of cancelling the whole update.
  • Counts saved before the mail fix are no longer trusted over complete ones. Records saved by an older version hold your bags and vault but no mail, so they read low. The addon now marks each saved record with what it covers, and falls back to the older complete figure until that character is scanned again — which happens by itself the next time they open and close their bank. Nothing to run and nothing to reset.
  • The addon now notices when guild members come and go, as it happens. It was supposed to watch for the "X has come online" messages and keep its own list of who is around — but a fault meant that watcher never actually ran, in every version ever released. The addon only found out who was online when the game handed it a full guild refresh. In between, it could try to send an order to someone who had already logged off, and it was slower to notice a banker coming online with items you were waiting for. It now tracks this properly and immediately.
  • Bank characters who leave the guild no longer linger. Removing a character from your bank list, or from the guild, could leave a ghost entry behind that showed as permanently waiting for data. Those cannot occur any more.
  • The inventory window no longer gets stuck on "Loading items...". If any single item in your guild bank failed to load, the addon stopped waiting for the whole batch — so one bad item hid everything and the window sat on the loading message indefinitely. Now a problem item is skipped and the rest still appear, and if something never loads at all the addon gives up after a few seconds and shows you what it has rather than waiting forever.
  • The status bar now shows when your character is sending inventory to someone. The bar along the bottom of the Inventory window has a "Tx" readout meant to show sends in progress — it counted the wrong thing and was stuck on zero, so it stayed blank no matter how busy the addon was. There was no way to tell the difference between "nothing is happening" and "the indicator is broken". It now shows the real number, turning amber while sends are in flight and red when you are at the limit. Sending itself was never affected — only your view of it.
  • Bank contents were being constantly re-checked and re-sent between guild members, for no reason. Each bank character's contents carry a short fingerprint, used to tell at a glance whether two players are holding the same thing. That fingerprint was supposed to be written once, by the bank character itself. Instead almost every player recalculated it — whenever anyone asked about a bank, whenever certain replies arrived, and when older saved data was upgraded. Because each player worked it out slightly differently, players who held identical contents kept concluding they disagreed, and asked each other for the data again. On a busy guild that is a lot of chatter with nothing behind it. The fingerprint is now written once, by the bank character whose bank it is, and everyone else passes it along untouched.
  • A bad fingerprint could spread from player to player and replace good data. The same recalculation meant a fingerprint invented by one player was sent on to the next, stored as if it were genuine, and passed on again — so a wrong value could travel the guild and overwrite correct bank contents, most visibly after the bank character had logged off and was no longer around to correct it. Players no longer accept a fingerprint from anyone except the bank character it belongs to.
  • Two different bank contents that happened to look identical are no longer mistaken for each other. The fingerprint now includes when the contents were recorded, so a genuine change is never mistaken for "nothing happened". This is also what lets the addon tell which of two copies is actually the newer one.
  • A bank character's contents could be replaced by an older copy, so items that were really there stopped showing. When several guild members each hold a copy of the same bank character, they pass it around between them. The addon applied whichever copy arrived last and never checked how old it was — so somebody logging in with a days-old copy could overwrite the up-to-date one for everyone, and there was nothing to say it had happened. It could not check, because a bank character's contents were sent without any record of when they were taken; each player stamped them with the time they received them, which meant a copy passed along third-hand looked newer than the original the further it travelled. Contents now carry the time they were actually scanned, and an older copy is ignored rather than applied.
  • The addon now tells you if the game has no room left for it to talk to your guild. WoW allows only a limited number of addon conversations at once, and once that limit is reached any further ones are simply refused. TOGBank could be one of the refused ones — and when that happened nothing was said. No error, no warning, just a guild bank that never updated, with nothing anywhere to explain why. It now checks, and if it has been shut out it says so plainly and tells you that disabling another addon and reloading will fix it. If everything is fine, as it will be for almost everyone, you will never see this.
  • The addon notices when the game refuses to send something. Occasionally the client declines to send an addon message. Previously that was reported back as success, so the addon believed your guild had received an update they never got — most importantly changes to orders, which could leave different members seeing different lists with nothing to explain why. Failed sends are now retried, and if they still fail you are told, instead of the addon quietly assuming it worked.

v1.3.2 (2026-08-03) - ElvUI & Baganator Item Highlighting

The "Highlight needed items" option now works for ElvUI and Baganator users.

New

  • "Highlight needed items" works with ElvUI. If you use ElvUI's bags, ticking the box did nothing at all — the addon only knew how to dim items in Bagnon and in the default Blizzard bags. It now dims unneeded items directly in ElvUI's bag and bank windows, using ElvUI's own shading so it looks native and doesn't interfere with ElvUI's search box. Unticking the box restores everything to normal. Works the same on Classic Era and TBC.
  • "Highlight needed items" works with Baganator. If you use Baganator for your bags, ticking the box did nothing — the addon only knew how to mark items in Bagnon and in the default Blizzard bags. Items you need for open orders now get a gold marker in the top-left corner of the icon. Note this looks different to the Bagnon and default-bag versions, which instead dim everything you don't need: Baganator only lets addons add corner markers, so that is the form it takes there. You can move or remove the marker from Baganator's own customise window, where it appears as "TOGBank: needed for an order".

Changed

  • Bagnon users are unaffected. If you run Bagnon underneath ElvUI with ElvUI's own bag replacement turned off, highlighting keeps using Bagnon exactly as before.

Please report anything odd with ElvUI or Baganator. Support for both was written against those addons' own published interfaces, but neither is installed on the development machine, so this release is the first time either has run for real. Both are built to fail quietly — if something is wrong they fall back to the previous behaviour rather than throwing errors — so if highlighting doesn't do what's described above, please report it and say which bag addon you use. Bagnon and default-bag users are on the same code path as before and unaffected either way.

v1.3.1 (2026-08-02) - Banker Inventory Never Scanned

Fixes a bank character's own items never being recorded, leaving their tab permanently empty.

Changed

  • Easier to diagnose if scanning ever stops. When the addon decides not to scan, it can now tell you why (for example, the character isn't marked as a bank, or scanning is switched off for them) instead of doing nothing silently. Turn on the new BANK category in the debug options if you are troubleshooting.

Fixed

  • Scanning can no longer switch itself off behind your back. Depending on timing at login, a bank character's "enable scanning" setting could end up unset — which silently stopped their bags and bank from being recorded — and the Bank section could be missing from the addon's options entirely, so the "Enable for <character>" tick box wasn't there to turn on. The setting now defaults to on and the options section is registered reliably. Affects Classic Era as well as TBC.
  • An empty tab no longer says "Loading items..." forever. A character with nothing recorded yet showed a loading message that never went away, so an empty record looked identical to the addon being stuck. Empty tabs now tell you what is actually going on — and, for your own character, what to do about it.
