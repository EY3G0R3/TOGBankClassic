TOGBankClassic - Guild Bank Management for Classic Era & TBC

Are you tired of logging into multiple bank alts to find items? Does your guild rely on character banks instead of the guild vault? TOGBankClassic is the solution!

TOGBankClassic is a powerful, feature-rich addon that transforms how your guild manages inventory across multiple bank characters. View, search, and request items from all your guild bank alts without ever logging out—all in one convenient interface.

Core Features

Unified Inventory Management

  • One-Click Access: View the complete inventory of all guild bank characters in a single window
  • No Alt-Hopping: Never log out to check what's in stock—see everything at a glance
  • Real-Time Updates: Inventory automatically syncs across all guild members using the addon
  • Mail Integration: Track items in transit—see what's in the mailbox as part of total inventory
  • Item Tooltip: Hover any item anywhere in-game to see which bankers have it and their exact stock levels—no addon window needed

Powerful Search System

  • Guild-Wide Search: Search across all bank characters simultaneously—find any item instantly
  • Live Filtering: Results update as you type, showing exact quantities and locations
  • Sort Dropdowns: Visual dropdown menus with 6-7 sort modes (A-Z, By Type, By Rarity, By Level, By Bank, By Quantity, By Slot) and reverse order toggle
  • Banker Labels: See which banker character has each item in search results
  • Click to Request: Click any search result to open a request dialog with smart quantity suggestions
  • Availability Info: See max requestable amounts based on officer-configured limits

Smart Request System

  • In-Game Requests: Guild members request items directly through the addon—no whispers needed
  • Request Tracking: View all pending, fulfilled, and completed orders in the Requests window
  • Timeline Tooltips: Hover any request's date to see when it was submitted, filled, or cancelled (with reason)
  • Cancel Reasons: Bankers select a reason before cancelling; reason is stored and shown to the requester
  • Requests Archive: Requests older than a configurable threshold automatically move to an Archive tab, keeping the main view focused
  • Stale Request Management: orders left unfilled past your chosen age close automatically, and officers can clear them in one go with the "Cancel Stale" button
  • Priority System: Mark requests as Rush, High, Normal, or Low priority for better organization
  • Officer Controls: Officers can configure guild-wide request percentage limits (1-100% of inventory)

Automated Order Fulfillment

  • One-Click Fulfill: Bankers click "Fulfill" button—addon automatically attaches items to mail
  • Smart Stack Splitting: Automatically splits oversized stacks with confirmation dialogs
    • Example: Request for 2 Felcloth from a 5-stack? Addon prompts to split precisely 2 items
    • Complex requests (e.g., 175 Runecloth from mixed stacks) handled automatically
  • Optimal Stack Selection: Intelligent bin-packing algorithm selects best stack combinations
  • Visual Indicators: Button icons change to show split needed vs. ready to mail

Blazing-Fast Synchronization

  • Only what changed gets sent. After the first sync, the addon shares just the differences rather than whole inventories — a fraction of the traffic of a full re-send.
  • No single bottleneck. Data comes from whichever guild member has the freshest copy, not from one designated player who has to be online.
  • Log in and catch up. Anything you missed while offline arrives shortly after you log in, without you asking.
  • Built to stay quiet. Traffic is queued and paced so a busy guild chat doesn't get flooded and messages don't arrive garbled.
  • Nothing to configure. All of this runs on its own; there are no sync settings to tune.

Advanced Features

For Guild Members

  • Minimap Button: Quick access to inventory—toggle visibility in options
  • Bag Highlighting: items needed for open orders are marked in your bags — works with the default bags, Bagnon, ElvUI and Baganator
  • Request History: View your past requests with fulfillment status
  • Fair Distribution: Officer-configured limits ensure equitable access to guild resources
  • Window Persistence: All window sizes and positions save automatically across reloads
  • Visual Consistency: Thin 8px scrollbars and unified borders across all windows
  • Mute Warnings: Checkbox to hide low-priority warnings for cleaner chat

For Bank Alts

  • Automatic Detection: Add "gbank" to Public Note or Officer Note—addon handles the rest
  • Auto-Scan: Configure to scan bank/bags/mail automatically when opened
  • Mail Fulfillment: Receive requests, click Fulfill, send mail—streamlined 3-step process
  • Donation Tracking: Optional feature to accept and track donations from guild members

For Officers

  • Request Limits: Set max request percentage (e.g., 50% = members can request up to half of available stock)
  • Protects Unique Items: Always allows requesting at least 1 if available (gear, BoE epics, etc.)
  • Syncs Guild-Wide: your settings reach everyone online straight away, and anyone who was offline picks them up when they next log in — you only set them once
  • Auto-Cancel Threshold: choose how many days an unfilled order stays open before it is closed as stale
  • Custom Cancel Reasons: write your own reasons for cancelling an order, and choose which ones members and bankers each see
  • Help Notes: add a note of your own to each window's help tooltip, so guild-specific rules are visible where people need them

If Something Goes Wrong

  • Built-in logging. Turn it on with /togbank debug, send it to its own chat tab with /togbank debugtab, and grab a copy for a bug report with /togbank debuglog. Off by default, so it costs you nothing when you're not using it.
  • Update notifications. You're told when a newer version is out, so you're not silently running an old one while your guild has moved on.
  • Diagnostics on request. If a problem needs digging into, there are extra tools behind /togbank dev that support can walk you through on Discord.

How It Works

Setup (One-Time)

  1. Bank Characters: Add "gbank" to character's Public Note or Officer Note
  2. Enable Reporting: In AddOns settings, enable "Report bank contents" and "Scan bank on open"
  3. Scan Inventory: Open your bank/bags/mail—addon scans and shares with guild
  4. Done! Inventory is now visible to all guild members using TOGBankClassic

Daily Usage

For Guild Members:

  1. Open TOGBankClassic (minimap button, or type /togbank)
  2. Click "Search" → type item name (e.g., "Felcloth")
  3. Click result → dialog shows available quantity
  4. Enter amount → click "Send Request"
  5. Wait for mail notification—it's that easy!

For Bank Alts:

  1. Open TOGBankClassic → click "Requests"
  2. See all pending requests with quantities
  3. Click "Fulfill" on any request
  4. Addon attaches items (auto-splits if needed)
  5. Type recipient name → send mail → done!

Slash Commands

Everyday Commands

  • /togbank — open or close the main inventory window
  • /togbank help — list every available command
  • /togbank roster — show the bank characters the addon knows about
  • /togbank sync — manually pull the latest data from your guild
  • /togbank share — push your own inventory and requests to the guild
  • /togbank version — show which version you are running
  • /togbank wipeframes — put all windows back to their default positions and sizes

/bank and /gbank can be enabled as shortcuts in the options, if nothing else has claimed them.

Resetting Data

  • /togbank wipe — clear this guild's stored data (it re-syncs from your guild afterwards)
  • /togbank wipeall — clear everything and start fresh

Troubleshooting

  • /togbank debug — turn debug messages on or off
  • /togbank debugtab — send debug messages to their own chat tab instead of cluttering yours
  • /togbank debuglog — print a recent slice of the log to paste into a bug report

There are further diagnostic commands behind /togbank dev, intended for development and support. /togbank dev help lists them; you should not need them in normal play.

Configuration

Access Options

  • Press ESC → Options → AddOns → TOGBankClassic
  • Or right-click the minimap button

Key Settings

  • Bank Section: Enable reporting, auto-scan on bank open, mail scan settings
  • Request Section: Configure request limits, priority display, mute warnings
  • UI Section: Minimap button visibility, window opacity
  • Debug Section: Enable persistent logging, toggle debug categories

Dependencies & Compatibility

Required

All of these install automatically through the CurseForge app — you do not need to fetch them yourself.

  • Ace3 — core framework
  • VersionCheck-1.0 — tells you when a new version is out
  • LibGuildRoster — guild roster and online/offline tracking
  • AceCommQueue — keeps addon traffic orderly so nothing arrives garbled

Optional — bag addons

The "Highlight needed items" option works with the default Blizzard bags and with the bag addons below. The look differs depending on which one you use — that is a limit of what each addon lets others change, not a bug:

  • Bagnon — dims the items you don't need. Limited to the first 20 distinct items.
  • ElvUI — dims the items you don't need, in both the bag and bank windows, using ElvUI's own shading.
  • Baganator — puts a gold marker on the items you do need. Nothing is dimmed, because corner markers are the only thing Baganator lets other addons add.

Compatibility

  • World of Warcraft Classic Era (Interface 11509)
  • World of Warcraft The Burning Crusade (Interface 20506)
  • Works alongside other guild management addons
  • Other bag addons are not interfered with, but item highlighting only supports the four listed above — everything else in the addon works normally regardless of which bag addon you run

Works With the Rest of the TOG Addons

TOG Profession Master

If your guild also runs TOG Profession Master, the two talk to each other automatically — there is nothing to set up on this side beyond having TOGBankClassic loaded.

  • Crafters can see guild bank stock without leaving the profession window. A [Bank] button appears next to any reagent your bankers actually hold — in the recipe breakdown, the cooldown panel, shopping lists and the Reagent Tracker. If nothing is in stock, no button.
  • They can request reagents from there too. Click [Bank], pick which banker to ask, choose a quantity, and the order arrives in TOGBankClassic like any other request — including your officer-configured limits.
  • No duplicate bookkeeping. TOG Profession Master reads the same stock figures this addon already keeps, so there is only ever one set of numbers to trust.

TOG Tools — planned

Not available yet. A bank log is planned, which will surface this addon's guild bank activity inside TOG Tools alongside the rest of its at-a-glance guild information. Listed here so you know it is coming, not as something you can use today — there is no date on it, and nothing in this addon depends on it.

Shared Foundations

The TOG addons are built on a common set of libraries rather than each reinventing the same plumbing:

  • DeltaSync — the guild-sync engine that keeps data current across members
  • LibGuildRoster — guild roster and online/offline tracking
  • AceCommQueue — keeps addon traffic orderly so nothing arrives garbled
  • ItemDB — an offline item database, so item names and details work without waiting on the game to load them
  • VersionCheck — tells you when a newer version is out

In practice that means a fix to the shared sync layer benefits every TOG addon at once, and running several of them costs less than the sum of their parts. Each is published separately and installs automatically through the CurseForge app.

Recent Updates

v1.4.0 (in development) - Guild Roster Overhaul

Not released yet. Listed so you can see what is coming.

  • EVENT-001: the addon now notices when guild members come and go, as it happens. It was supposed to watch for the "X has come online" messages and keep its own list of who is around — but a fault meant that watcher never actually ran, in every version ever released. The addon only found out who was online when the game handed it a full guild refresh. In between, it could try to send an order to someone who had already logged off, and it was slower to notice a banker coming online with items you were waiting for. It now tracks this properly and immediately.
  • Bank characters who leave the guild no longer linger. Removing a character from your bank list, or from the guild, could leave a ghost entry behind that showed as permanently waiting for data. Those cannot occur any more.
  • ITEM-005: the inventory window no longer gets stuck on "Loading items...". If any single item in your guild bank failed to load, the addon stopped waiting for the whole batch — so one bad item hid everything and the window sat on the loading message indefinitely. Now a problem item is skipped and the rest still appear, and if something never loads at all the addon gives up after a few seconds and shows you what it has rather than waiting forever.
  • ACQ-004: the addon notices when the game refuses to send something. Occasionally the client declines to send an addon message. Previously that was reported back as success, so the addon believed your guild had received an update they never got — most importantly changes to orders, which could leave different members seeing different lists with nothing to explain why. Failed sends are now retried, and if they still fail you are told, instead of the addon quietly assuming it worked.
  • Two addons are now installed alongside this one: LibGuildRoster and AceCommQueue. Guild-roster handling and message queueing moved into shared libraries used across the TOG addons, so a fix in either benefits all of them at once. AceCommQueue was previously bundled inside TOGBankClassic and had fallen behind its own newer releases; as a separate addon it stays current. Both install automatically through the CurseForge app — you do not need to fetch either yourself.

v1.3.2 (2026-08-03) - ElvUI & Baganator Item Highlighting

The "Highlight needed items" option now works for ElvUI and Baganator users.

  • BAGANATOR-001: "Highlight needed items" works with Baganator. If you use Baganator for your bags, ticking the box did nothing — the addon only knew how to mark items in Bagnon and in the default Blizzard bags. Items you need for open orders now get a gold marker in the top-left corner of the icon. Note this looks different to the Bagnon and default-bag versions, which instead dim everything you don't need: Baganator only lets addons add corner markers, so that is the form it takes there. You can move or remove the marker from Baganator's own customise window, where it appears as "TOGBank: needed for an order".
  • ELVUI-001: "Highlight needed items" works with ElvUI. If you use ElvUI's bags, ticking the box did nothing at all — the addon only knew how to dim items in Bagnon and in the default Blizzard bags. It now dims unneeded items directly in ElvUI's bag and bank windows, using ElvUI's own shading so it looks native and doesn't interfere with ElvUI's search box. Unticking the box restores everything to normal. Works the same on Classic Era and TBC.
  • Bagnon users are unaffected. If you run Bagnon underneath ElvUI with ElvUI's own bag replacement turned off, highlighting keeps using Bagnon exactly as before.
  • Please report anything odd with these two. The ElvUI and Baganator support was written against those addons' own published interfaces, but neither is installed on the development machine, so this release is the first time either has run for real. Both are built to fail quietly — if something is wrong they fall back to the previous behaviour rather than throwing errors — so if highlighting doesn't do what's described above, please report it with the ticket ID (ELVUI-001 or BAGANATOR-001) and it'll be fixed quickly. Bagnon and default-bag users are on the same code path as before and unaffected either way.

v1.3.1 (2026-08-02) - Banker Inventory Never Scanned

Fixes a bank character's own items never being recorded, leaving their tab permanently empty.

  • SCAN-001: Scanning can no longer switch itself off behind your back. Depending on timing at login, a bank character's "enable scanning" setting could end up unset — which silently stopped their bags and bank from being recorded — and the Bank section could be missing from the addon's options entirely, so the "Enable for <character>" tick box wasn't there to turn on. The setting now defaults to on and the options section is registered reliably. Affects Classic Era as well as TBC.
  • An empty tab no longer says "Loading items..." forever. A character with nothing recorded yet showed a loading message that never went away, so an empty record looked identical to the addon being stuck. Empty tabs now tell you what is actually going on — and, for your own character, what to do about it.
  • Easier to diagnose if scanning ever stops. When the addon decides not to scan, it can now tell you why (for example, the character isn't marked as a bank, or scanning is switched off for them) instead of doing nothing silently. Turn on the new BANK category in the debug options if you are troubleshooting.

v1.3.0 (2026-08-02) - TBC Client Support

TOGBankClassic now installs and runs on The Burning Crusade clients as well as Classic Era.

  • TBC-001: The addon now loads on TBC. Previously only a Classic Era build was published, so TBC players saw the addon flagged as out of date and had to force-load it. There is now a proper TBC build with the same features, same commands and same interface — install it the usual way and it just works.
  • No longer flagged "out of date" on Classic Era. The Era build was still marked for the previous game patch, so it showed up greyed out in the AddOns list until you ticked "Load out of date AddOns". It now matches the current patch.

v1.2.1 (2026-07-30) - Settings Panel Open Fix

Fixes the settings panel refusing to open after a recent client update.

  • SETTINGS-002: The settings panel opens again. Clicking the gear icon in the bank window, or picking Settings from the minimap button, threw an error and nothing opened. A recent change to how the game's Settings window is addressed meant the addon was asking for its options page the old way. Both buttons now take you straight to the TOGBankClassic options page.

Older patch notes are in the addon's CHANGELOG.md file (ships with the addon).
